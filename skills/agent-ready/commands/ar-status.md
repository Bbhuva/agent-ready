Tell the operator where the project stands, in plain words, in under ten lines.

1. Run `node .agents/scripts/board.mjs` and read `docs/build/README.md`.
2. Say: the current phase and how far along it is; what is in progress and by whom; what is ready next; what is blocked, and on what.
3. List their open to-dos from `docs/operator/todo.md` (ID and title) and any checks waiting for them in `docs/operator/mtest.md`.
4. End with the one thing you suggest doing next, as a command, like `/ar-next`.
