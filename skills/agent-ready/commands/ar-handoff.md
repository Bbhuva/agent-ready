Write a handoff so the next session can pick up without this chat. Topic, if they gave one: $ARGUMENTS

Copy `docs/build/templates/handoff.md` to `docs/build/handoffs/<date>-<topic>.md` and fill it in: where things stand, what changed, what was and wasn't checked, claims still held, open decisions, the next steps in order, and what only the operator can do.

Then tell the operator the file name, and that a fresh session can start with: "Read AGENTS.md, then <that file>, and carry on."
